# 🐍 Python Mini Projects

A collection of beginner-friendly Python projects built to practice programming fundamentals, improve problem-solving skills, and develop practical applications.

This repository includes small projects such as a **To-Do App, ATM Simulator, Calculator, QR Code Generator**, and more. Each project focuses on applying Python concepts to real-world use cases.

## 🚀 Projects

| # | Project | Description | Concepts Used |
|---|---|---|---|
| 1 | To-Do App | Manage daily tasks and keep track of activities. | Lists, Functions, File Handling |
| 2 | ATM Simulator | Simulate basic ATM operations such as checking balance and withdrawing money. | Conditional Statements, Loops, Functions |
| 3 | Calculator | Perform basic arithmetic operations. | Functions, Operators, User Input |
| 4 | QR Code Generator | Generate QR codes from text or URLs. | Python Libraries, Input Handling |


## 🛠️ Technologies Used

- **Language:** Python
- **Libraries:** Project-specific libraries, such as `qrcode`, where required
- **Tools:** Git and GitHub
- **Concepts:** Variables, Data Types, Loops, Functions, Conditional Statements, Object-Oriented Programming, and File Handling

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Python-Mini-Projects.git
```

### 2. Navigate to the Project Folder

```bash
cd Python-Mini-Projects
```

### 3. Run a Project

Navigate to the desired project directory and run its Python file:

```bash
python main.py
```

**Note:** Some projects may require additional Python libraries. Install the dependencies listed for the specific project before running it.
